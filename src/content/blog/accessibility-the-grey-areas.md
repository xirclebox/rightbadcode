Have you ever had a questionable design choice that doesn't actually fail any specific rule in the WCAG, but it feels like it should? For example, let's start simple. How many H1 tags can we have on a web page? The answer is as many as your heart desires. Ok... how many H1 tags can be on a page for the markup to be valid? The answer is one. That's because we want to make sure our content is structured correctly. Now where this is not a direct WCAG violation, it is one that goes against best practices.
